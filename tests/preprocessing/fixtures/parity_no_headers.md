Senior Backend Developer

This role is perfect for an experienced software engineer looking to make an impact on a growing platform. We're seeking a Backend Developer with a passion for clean code and scalable architecture.

You will be responsible for building and maintaining the core backend services that power our application. Must have 5+ years of experience with Python and Django. Requires strong knowledge of PostgreSQL and Redis for caching.

Experience with Kubernetes and Docker is essential. You should be comfortable working with microservices architecture and have demonstrated proficiency in writing unit tests and integration tests. Knowledge of RESTful API design patterns is a must.

We're looking for someone with excellent problem-solving skills and the ability to work in a fast-paced environment. Experience with cloud platforms like AWS or GCP is highly valued. Proven experience shipping features to production is required.

The ideal candidate will have a BS in Computer Science or equivalent professional experience. We need strong communication skills and the ability to mentor junior developers.
